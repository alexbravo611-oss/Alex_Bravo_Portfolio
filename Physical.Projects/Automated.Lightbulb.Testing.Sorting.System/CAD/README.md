# CAD Files for Automated Lightbulb Testing & Sorting System

This folder contains all CAD assets for the project, including the Fusion 360 model, STEP file, STL file, and rendered views.

## Included Files
- Fusion 360 model (.f3d)
- STEP file (.step)
- STL file (.stl)
- Rendered views (PNG)
